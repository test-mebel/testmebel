# TEST MEBEL — mahsulotlarni sertifikatlashtirish organi sayti

Statik sayt (HTML/CSS/JS), uch tilda: o‘zbek (asosiy papka), rus (`ru/`), ingliz (`en/`).

## Tahrirlash
- Har bir sahifa alohida `.html` fayl; matn `<main>` ichida.
- Bir sahifani o‘zgartirsangiz, `ru/` va `en/` dagi shu nomli faylni ham o‘zgartiring.
- Menyu va footer har sahifada takrorlanadi.
- Ranglar va shriftlar — `css/style.css`.
- Yuklab olinadigan hujjatlar — `docs/`.

## GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, papka: `/ (root)` → Save.
O‘z domeni (testmebel.uz) ulansa: Settings → Pages → Custom domain.
